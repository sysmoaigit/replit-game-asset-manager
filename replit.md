# Workspace

## Overview

pnpm workspace monorepo using TypeScript. Each package manages its own dependencies.

## Artifacts

### Selim in Dhaka (artifacts/selim-in-dhaka)
- **Kind**: Web game (also installable as PWA on Android & iPhone, and packageable as native app via Capacitor)
- **Port**: 21026, previewPath: `/`
- **Stack**: React + Vite + TypeScript + Tailwind CSS + framer-motion
- **Mobile / PWA**:
  - `vite-plugin-pwa` generates `manifest.webmanifest` + service worker (`sw.js`) on production builds. Installable on Android Chrome and iOS Safari ("Add to Home Screen") with full-screen `display: standalone`.
  - App icons & iOS splash screens generated by `pnpm run icons` (sources: `public/app-icon.svg`, `public/app-icon-maskable.svg`; outputs in `public/icons/`).
  - `index.html` includes `viewport-fit=cover`, theme-color, Apple PWA meta tags, and per-device splash screen `<link>` tags.
  - `index.css` honors `env(safe-area-inset-*)` so the dark backdrop paints into iPhone notch / Android gesture bar; inputs use 16px+ font-size to prevent iOS zoom on focus.
  - Service worker is **disabled in dev** (`devOptions.enabled: false`) to keep HMR clean — only active on built/deployed app.
- **Capacitor (native iOS/Android shells)**:
  - `capacitor.config.ts` at the artifact root (appId `com.selim.dhaka`, webDir `dist/public`).
  - To produce native projects (one-time): `pnpm --filter @workspace/selim-in-dhaka run cap:add:android` and (on macOS) `cap:add:ios`. After web changes: `pnpm --filter @workspace/selim-in-dhaka run cap:sync`.
  - `build:mobile` script forces `BASE_PATH=/` so asset URLs resolve correctly inside the WebView (the workspace dev base `/selim-in-dhaka` would 404 inside Capacitor).
  - Building actual `.apk` / `.ipa` binaries requires Android Studio (any OS) and Xcode (macOS only) — neither runs inside Replit; you must run those steps locally after exporting the project.
- **Persistence**: localStorage (key: `selim_dhaka_save`)
- **Language**: Bangla (Bengali) UI with Hind Siliguri font
- **Description**: Mobile-first swipe decision game. Player navigates 15 days in Dhaka as Selim, making choices across 77+ cards in 7 categories.
- **Game loop**: 4 phases/day → Day Summary → Next Day. After Day 15 → Ending. Recovery mode triggers if health<25 && addiction>50 or addiction>=100.
- **Key files**:
  - `src/types.ts` — GameState, Stats, Flags, GameCard, Achievement types
  - `src/game/engine.ts` — Pure game logic (selectCard, applyEffects, checkDanger, evaluateEnding, save/load)
  - `src/game/cards.ts` — 77+ GameCard objects (all categories + recovery)
  - `src/game/endings.ts` — 6 endings (smart_survivor, healthy_selim, biryani_king, influencer, recovery_hero, lost_selim)
  - `src/App.tsx` — Main game loop (useState, screen routing, all handlers)
  - `src/components/` — StartScreen, Tutorial, GameScreen, DaySummary, RecoveryMode, EndingScreen, Menu, DecisionCard, StatBars, SelimAvatar
- **Audio**: 32 AI-generated Selim voice MP3s in `public/audio/voice/selim/` (generated via OpenAI `gpt-audio` model with `ash` voice). Engine in `src/game/audioEngine.ts` falls back to subtitles for missing files. SFX/ambience folders are intentionally empty for user-supplied clips.
- **Bangla TTS** (`src/lib/selimVoice.ts`): Web Speech API wrapper with reactive voice loading, emoji/punctuation sanitization, sentence chunking on `। ! ? .`, per-speaker gendering (`speaker: "selim" | "girl"`), and **strict-Bangla mode** (default ON) that skips speech entirely when no `bn-*` voice is installed — prevents the "English voice garbling Bangla characters" failure mode. Player controls in SoundSettings: voice picker (`voice-picker`), speed slider (`voice-rate`, 0.5–1.3×, default 0.85×), strict toggle, test button (`btn-test-voice`), and OS install help when no Bangla voice is found. Prefs persisted at localStorage `selim_voice_prefs_v1`. `GirlfriendVoicePreview` falls back to TTS when an audio clip is missing.
- **Music engine** (`src/audio/sounds.ts` `startMusic`): BD raga-flavored procedural music. Six raga scales (Bhairavi, Yaman, Bhairav, Khamaj, Bhupali, Desh) drive 14 mood tracks (intro, menu, day, night, love, tense, recovery, victory, defeat, boss, simp, rock_bottom, chad, pinky_anthem). Each playback is unique: random key transposition (±3 semitones), random tempo jitter (±15%), random melodic phrase from the mood's pattern bank, gamak slide ornaments, and pattern auto-swap every 12-16 notes. Tampura drone (root + perfect 5th + detuned warmth) + tabla percussion (teental/dadra/kaharwa cycles). Mood-aware picker in App.tsx (`musicTrack` useMemo) routes based on Selim's actual stats: rock_bottom (high addiction + low self-respect) → bhairavi sawtooth; chad_mode (high self-respect + career) → bhupali triangle; pinky_anthem (high pinky_hope + delusion) → khamaj soaring; bogura_boss (career endings) → khamaj swagger; pinky_simp (romantic fever) → yaman slow; etc. Drop your own `.mp3` files into `public/audio/music/<trackId>.mp3` to override the procedural version automatically (audioEngine tries MP3 first, falls back to procedural).
- **Dev panels (DEV-only, hidden in prod)**:
  - `QAPanel.tsx` — bottom-left 🛠 button. Tabbed playground: 🎯 State (live stat sliders for all 17 stats + key-flag inspector + Selim mood mirror), ⚡ Force (force any of 23 endings, jump screens, search/force any card), 🎨 Presets (12 one-click vibes: Pinky Simp, Bogura Boss, Broke, Chad, Touba Loop, Recharge Romeo, Healthy, Galaxy Brain, Influencer, Rock Bottom, Biryani King, Eternal Crush + day travel + wallet cheats), 🎲 Chaos (full randomizer + bulk unlock all scenes/eggs + per-egg toggle list + reset bombs), 📚 Album (scene grid preview + missing assets). All actions log to a 6-line in-panel feed.
  - `AudioDebugPanel.tsx` — top-left 🎵 DBG button. Tabs: 🎚 Mix (4 volume sliders + 4 toggle pills + voice freq + accent + humor), 🎵 Bed (8 music tracks + 13 ambience locations), 🎤 Voice (filter all 166 voice lines by speaker/category/text → click to play), 💥 SFX (full ESSENTIAL_SFX grid), 🔍 Missing (live missing-file list).

## Stack

- **Monorepo tool**: pnpm workspaces
- **Node.js version**: 24
- **Package manager**: pnpm
- **TypeScript version**: 5.9
- **API framework**: Express 5
- **Database**: PostgreSQL + Drizzle ORM
- **Validation**: Zod (`zod/v4`), `drizzle-zod`
- **API codegen**: Orval (from OpenAPI spec)
- **Build**: esbuild (CJS bundle)

## Key Commands

- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- `pnpm --filter @workspace/api-server run dev` — run API server locally

See the `pnpm-workspace` skill for workspace structure, TypeScript setup, and package details.
